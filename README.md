# Suspicious_Activity_Detection
A real-time surveillance system using YOLOv8 and OpenCV to detect suspicious movements and falling incidents, triggering an audio alarm when detected.

## Technologies Used
- Python
- OpenCV
- YOLOv8 Pose Estimation
- NumPy
- Pygame

## Features
- Real-time human pose detection
- Movement speed analysis
- Fall detection
- Suspicious activity alerts
- Audio alarm notification

## How to Run
1. Install the required libraries.
2. Keep the model and alarm files in the project folder.
3. Run `python main.py`.
